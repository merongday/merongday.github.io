개인정보처리방침

시행일: 2026년 11월 20일

누가 쓰나요

소나기는 만든 사람 본인 한 명만 쓰는 개인용 프로그램입니다. 다른 사용자를 받지 않습니다.

어떤 구글 데이터에 접근하나요

  • 구글 캘린더: 본인 일정을 읽고, 본인이 요청한 일정을 등록·수정·삭제합니다.
  • 지메일: 영수증·생활 알림을 읽고, 광고·업데이트 메일을 휴지통으로 옮깁니다. 메일을 대신 보내지 않습니다.
  • 구글 연락처: 이름·회사·직함만 읽습니다(읽기 전용).
  • 유튜브: 본인 계정의 재생목록 하나에 곡을 넣고 뺍니다.

데이터는 어디에 두나요

가져온 데이터는 본인 소유의 컴퓨터 한 대에만 저장하며, 다른 사람이나 회사에 팔거나 넘기지 않습니다. 광고에 쓰지 않습니다.

구글 API 서비스 사용자 데이터 정책

소나기가 구글 API에서 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

삭제

구글 계정 설정의 '타사 앱 및 서비스'에서 언제든 접근 권한을 해제할 수 있고, 저장된 데이터는 본인이 컴퓨터에서 지웁니다.
